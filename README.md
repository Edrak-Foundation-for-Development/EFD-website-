# موقع مؤسسة إدراك للتنمية

موقع Astro ثابت، ثنائي اللغة، ومهيأ للنشر على Cloudflare Pages.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## فحص وبناء المشروع

```bash
npm run check
npm run build
```

## إعداد Cloudflare Pages

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 20 أو أحدث

## قبل الإطلاق

1. استبدال شعار EFD المؤقت بالشعار الرسمي.
2. استبدال الصور التجريبية في `public/images`.
3. تحديث بيانات التواصل والعنوان والهاتف.
4. تحديث المؤشرات والأرقام في الصفحة الرئيسية.
5. إضافة المحتوى الفعلي للمشاريع والأخبار والقصص والتقارير.
6. ربط النماذج بخدمة مثل Cloudflare Pages Functions أو خدمة نماذج موثوقة.
7. تعديل `site` في `astro.config.mjs` إذا تغير النطاق.

جميع النصوص والأرقام والصور الحالية تجريبية، باستثناء الاسم والرابط المعتمدين للمؤسسة.
